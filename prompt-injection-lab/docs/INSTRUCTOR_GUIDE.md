# 강사 가이드

PPT 파일의 실제 슬라이드 순서로 70장은 공통 환경, 71장은 Direct, 73장은 Role Playing, 75장은 Indirect 실습에 대응합니다. 서버를 미리 실행하고 학생 브라우저에서 로컬 주소를 열어 주세요. 첫 설치 후 Mock에서는 인터넷과 모델이 필요하지 않습니다.

수업 흐름: 정상 입력 → 공격 변형 → 실제 응답과 규칙 비교 → 실험 기록. 예상 모의 결과: Direct에서 출력 형식을 바꾸는 지시는 형식 위반을 일으킬 수 있습니다. Indirect 문서에 특정 부가 문구를 추가하도록 지시하면 취약 Target의 답변 끝에 해당 문구가 나옵니다.

Mock은 제한된 패턴을 시연하는 결정적 모델입니다. Live 모드는 모델별 편차가 크며 정확한 운영시간 추출 외 일탈은 보수적으로 판정 보류할 수 있습니다. 구문 검증과 예시 문구 검사만으로 모든 공격을 판정할 수 없습니다.

개인 정보와 실제 키를 입력하지 않도록 안내하세요. 기록은 이 컴퓨터의 `data/attempts.jsonl`에 남으며, 제거된 실습의 기존 기록도 전체 내보내기에 보존됩니다.
